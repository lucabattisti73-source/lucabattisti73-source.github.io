Informativa privacy

Lezioni Pipeline è un'applicazione ad uso esclusivamente personale.

  • Dati letti: file audio e cartelle all'interno della cartella Google Drive "Lezioni" indicata dal proprietario.
  • Trattamento: gli audio vengono scaricati e trascritti su un server privato del proprietario; il testo trascritto viene elaborato tramite Claude (Anthropic) per generare dispense di studio.
  • Dati scritti: file PDF e file di stato nella stessa cartella Drive.
  • Conservazione: trascrizioni conservate sul server per un massimo di 30 giorni, poi eliminate. Gli audio non vengono conservati.
  • Condivisione: nessun dato viene venduto, ceduto o usato per pubblicità.
  • Revoca: l'accesso può essere revocato in qualsiasi momento da https://myaccount.google.com/permissions
